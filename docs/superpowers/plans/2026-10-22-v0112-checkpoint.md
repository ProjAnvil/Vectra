# v0.11.2 增量 checkpoint 实施计划（WAL 保留式）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** checkpoint 从 O(N) 全量快照改为 O(1) manifest 轮转；增量 = 保留的 WAL 段链；压缩（全量写）按保留字节数阈值触发，界住恢复成本。

**Architecture:** `checkpoint()` 拆两档——轻量档（新建 WAL 段、manifest v2 记 `RetainFrom`、**不删**旧段、不写快照）与压缩档（今天的全量路径：SaveFile v6 + 删保留段 + 写 forest）。加载 = base + 从 RetainFrom 起的段链重放 + 活动尾（重放机制全部现成）。旧读者绊线 = base 快照版本 v6（v0.11.0/1 硬失败，杜绝"读 base 丢增量"的静默损失）。

**Spec:** docs/benchmarks/2026-10-22-v0112-scope.md 项 4（本计划细化并取代其 delta-文件草案；裁定记录见 SDD 台账）。

**Tech Stack:** Go，零第三方依赖，无 cgo。

## Global Constraints

- go.mod 零新增 require；无 cgo；英文 commit/comment。
- 每任务 TDD；完成后三模块 `go test ./...` + 相关包 `-race`；验收类单独跑。
- 门 2b 三线与 wrapper cadence 数不劣化（复跑时单独跑）。
- 旧版本兼容纪律：任何新库状态必须让 v0.11.1 及更早二进制**硬失败**而非静默丢数据（v6 版本绊线；同 store v3→v4/v5 先例）。
- 迁移链保持：v4/v5 →（Open 时）→ v6 base + 全量；幂等。

## Review Focus

1. **静默损失面**：manifest v2 新字段被旧读者忽略后读到什么？必须只能走到 v6 硬失败，不存在"base-only 成功打开"路径（含 ModeOff？ModeOff 不读 WAL/manifest——但 ModeOff 打开 v6 文件必须硬失败，验证）。
2. **崩溃窗口**：轻量档（新段已建、manifest 未落）与压缩档（新 base 已写、manifest 未落 / manifest 已落、旧段未删）各自的下一次 Open 行为；torn 尾纪律沿用。
3. **段链完整性**：RetainFrom 起的连续性（gap 即停）；salt 链不因保留而破坏；w.bytes 记账在轻量轮转后归零。
4. **forest 语义**：forest 仅压缩档写入；加载门放宽为"forest LSN ≥ base LSN 且 CRC/声明匹配"（陈旧 forest + 段重放覆盖窗口，重放幂等靠 State.Add 扫描序去重）；不匹配仍弃用重建。
5. **重放正确性**：保留段 + 活动尾按 LSN 连续应用；v2 帧与 v1 帧混链（迁移后立即轻量档的场景）。

### Task 2: manifest v2 + WAL 轻量轮转

**Interfaces:**
```go
// Rotate starts a fresh segment without deleting prior ones: the
// retained segment chain is the incremental checkpoint (manifest v2
// RetainFrom names the first live one). Reset remains the compacting
// form (delete everything below the new segment).
func (w *WAL) Rotate() error
```
- Manifest v2 写出：`WriteManifest(dir, Manifest{Snapshot, Segment, LSN, RetainFrom, Format:2})`；`Format` 0/缺省 = v1 旧文件。
- replayLSN 起点：`startSeg` 取 `min(man.Segment, man.RetainFrom)`（RetainFrom>0 时）——旧 manifest 无该字段时行为不变。
