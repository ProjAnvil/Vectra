# Vectra v2 Implementation Plan（服务模式 + 模块重构 + 工程化）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans。步骤用 checkbox 跟踪。

**Goal:** 按 [spec](../../specs/2026-10-12-vectra-v2.md)（已经子代理审计修订）交付：模块重构、引擎小能力（Clone/属性索引/谓词过滤/快照 v2 CRC）、独立 server 模块（hashicorp/raft 复制 + HTTP API + 热替换发布）、覆盖率与 modern-go 加固。

**Architecture:** 核心 module 零依赖不变；`internal/engine`（密封快照+访问器）、`internal/traverse`（算法）从根包拆出；`server/` 独立 go.mod 包 raft。FSM=live 可写图+发布器（RLock 克隆→锁外 Seal→atomic.Pointer 交换）。

**Tech Stack:** Go（核心与 server 均 `go 1.27.2`——replace 下依赖指令不得高于主模块；本地工具链 1.27.2 兼容）、hashicorp/raft v1.8.0、raft-boltdb/v2、stdlib net/http + encoding/gob + expvar。

## Global Constraints

- 现有 93 项测试**不修改断言**全部保持绿（重构行为零变化）。
- 核心 module go.sum 不出现（零第三方依赖）；全部新依赖只进 server/go.mod。
- TDD：每项新能力先写失败测试。每个 Task 结束 commit。
- raft-boltdb 传递依赖实现期 `go mod graph` 核实（spec 风险表）。

### Task 3: server 模块 — Batch/FSM/发布器/Node 生命周期

**Files:** Create `server/go.mod`（module vectra/server, `go 1.27.2`, replace vectra => ../）、`server/batch.go`、`server/fsm.go`、`server/node.go`；Test `server/fsm_test.go`。

**Steps:**
